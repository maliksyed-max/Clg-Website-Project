# College Website Project

A web-based college website developed to provide students and visitors with convenient access to college information, notices, news, events, and other institutional resources.

## Features

- College information and navigation
- Notices and announcements
- Latest news and events
- Tenders and quotations
- Downloadable documents, where available
- Organized web pages with a responsive interface

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Templates:** HTML templates rendered using Flask
- **Configuration:** Python configuration files

The project also includes route modules, static assets, and a data directory.

## Running Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/maliksyed-max/Clg-Website-Project.git
   cd Clg-Website-Project
   ```

2. Create and activate a virtual environment:

   ```bash
   python -m venv venv
   ```

   On Windows:

   ```bash
   venv\Scripts\activate
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure any required environment variables and database credentials according to the application's configuration.

5. Start the application:

   ```bash
   python app.py
   ```

6. Open the local URL displayed in the terminal.
